**目的**: 验证算子选择机制的理论主张

#### 实验设计
```python
# 1. 单频信号测试
# 验证：FFT算子在单频信号上获得最高权重
signal = np.sin(2πf₀t)
预期：FFT_weight > 0.8, 其他权重 < 0.05

# 2. 双频信号测试
# 验证：多算子协同激活
signal = np.sin(2πf₁t) + 0.5*np.sin(2πf₂t)
预期：FFT + WF 权重之和 > 0.7

# 3. 瞬态信号测试
# 验证：HT算子对瞬态特征敏感
signal = np.exp(-(t-t₀)²/σ²) * np.sin(2πf₀t)
预期：HT_weight > 0.6

# 4. 噪声信号测试
# 验证：算子注意力在噪声下的鲁棒性
signal = clean_signal + noise
预期：权重分布保持稳定
```

#### 验证指标
1. **算子选择准确性**: 权重分布是否符合物理预期
2. **权重稳定性**: 噪声下权重变化幅度
3. **解释一致性**: 与信号处理理论的一致程度
4. **可视化清晰度**: 权重演化图的可读性
