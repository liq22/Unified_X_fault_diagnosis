## 一、总览

### 1.1 项目定位
- **研究领域**：可解释故障诊断、专家系统
- **核心创新**：物理同构专家 + 可审计路由的MoE架构
- **目标期刊**：IEEE Transactions on Industrial Informatics (IF: 12.3)
- **创新等级**：方法创新 + 可解释性突破

### 1.2 核心贡献
1. **物理知识引导的专家设计**：
   - LowFreq专家：处理低频振动、转子不平衡
   - Harmonic专家：分析谐波成分、齿轮故障
   - Envelope专家：检测包络特征、轴承故障

2. **信号处理层集成**：
   - 每个专家内部集成FFT、HT、WF、LNO等信号处理算子
   - 4层信号处理架构

3. **三层可解释性框架**：
   - 专家级：专家激活权重分析
   - 信号级：信号处理算子贡献度
   - 故障级：物理特征映射解释

4. **参数效率突破**：
   - 仅36K参数达到93.85%准确率
   - 比ResNet26M减少99.86%参数量

## 三、技术架构

### 3.1 物理专家库
```python
Expert_Design = {
    'LowFrequency': {
        'target': '转速频率、边带成分',
        'physics': '转动不平衡、不对中',
        'signals': ['I', 'WF']
    },
    'Harmonic': {
        'target': '谐波成分、调制特征',
        'physics': '齿轮啮合、轴承故障',
        'signals': ['FFT', 'HT']
    },
    'Envelope': {
        'target': '包络特征、冲击响应',
        'physics': '滚动体故障、剥落',
        'signals': ['HT', 'LNO']
    }
}
```

### 3.2 智能路由器
- **基础**：13种统计特征（均值、标准差、峭度、RMS等）
- **路由熵**：平均0.8265，确保决策多样性
- **负载均衡**：防止专家使用不均

### 3.3 模型配置
- **输入维度**：[batch_size, 2, 4096]
- **信号处理**：1D CNN + 自适应池化
- **专家输出**：[batch_size, 10]
- **最终输出**：[batch_size, 5]（5分类）
