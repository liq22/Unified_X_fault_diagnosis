# 阶段3：7个 Paper 跨项目集成实验计划（2024-11-26）

> 目标：在阶段2“各自跑通 & 接口统一”的基础上，系统性开展跨项目集成实验，形成论文级结果矩阵：  
> - 与 `model_collection` 的统一性能对比  
> - 各方法之间的组合与对比  
> - 统一的可解释性评估与 NeSy 框架分析  
> 覆盖主数据集（优先 THU_006 / THU_018），并为后续投稿直接提供结果基础。

---

## 一、阶段3整体目标与边界

1. **统一基线与配置**  
   - 所有实验优先使用：  
     - 数据：`data/vbench_dataset.py` + `vbench_utils.py`；  
     - 训练：`trainer/` 中统一训练循环；  
     - 可解释性：根目录 `explainability/` + Explainable_FD_Toolkit API。  
2. **跨项目集成重点**  
   - 1D-2D 📘 + Explainable Toolkit 🟢：多模态模型的统一解释与对比。  
   - MoE 🟠 + Operator Attention 🔴：路径级 MoE vs 算子级 Attention 对比与组合。  
   - Fuzzy 🩷 + Neuralsymbolic 🟦：规则-神经混合在 NeSy 框架中的位置与性质。  
   - LLM Interface 🟣 + Toolkit 🟢：LLM 解释质量与效率评估。  
3. **阶段3不做的事**  
   - 不追求所有组合穷举，只选**最有代表性的组合**做深度实验。  
   - 不对基础设施做大改动，如需轻微调整，先在小范围验证。

## 三、各项目在阶段3中的核心任务（高层）

### 🟢 Explainable FD Toolkit
- 提供统一实验管线：  
  - 批量运行接口：模型 × 解释方法组合；  
  - 统一评估指标：覆盖度、稳定性、一致性、时间开销。  
- 输出：  
  - 多模型多方法解释性主表；  
  - 统一结果格式（CSV/JSON）供论文与其他工具使用。

### 🟦 Neural-Symbolic Theory
- 将阶段3实验结果映射到四层框架：  
  - 明确每个方法的层级贡献与符号元素；  
  - 选取 2–3 个关键实验作为理论命题的支撑案例。  
- 输出：  
  - NeSy 论文中的实验对照表；  
  - “设计模式”示例：哪些组合在什么场景下更合适。

### 🔴 Operator Attention
- 在 TSPN 或相关模型上完成：  
  - baseline vs Self-Attention vs Operator Attention 的性能/复杂度对比；  
  - 算子权重的可解释性分析（跨故障类型/工况）。  
- 输出：  
  - TII 论文所需表格与图；  
  - 与 MoE/1D-2D 的对比讨论输入。

### 📘 1D-2D Fusion
- 在统一基线下完成：  
  - 单模态 vs 多模态早期/中期/渐进融合的性能对比；  
  - 三层对齐指标与可解释性评估。  
- 输出：  
  - 多模态性能主表；  
  - 对齐质量与可解释性主表；  
  - 几张关键对齐/归因可视化图。

### 🟣 LLM Interface
- 利用 Toolkit 输出的解释结果完成：  
  - 传统可视化解释 vs LLM 解释的质量与效率对比实验；  
  - 若干完整对话案例。  
- 输出：  
  - 解释质量/效率对比表；  
  - 对话案例集。

### 🟠 MoE Expert
- 完成：  
  - NNSPN / 黑盒 MoE / NNSPN-MoE 的统一对比；  
  - 物理同构可解释性定量指标（路径稀疏度、专家分工、物理一致性）。  
- 输出：  
  - MoE 性能与解释性主表；  
  - 路径签名、专家激活模式等关键图。

### 🩷 Fuzzy Logic
- 完成：  
  - 纯模糊 / 纯深度 / Fuzzy-XFD 混合方案的性能对比；  
  - 规则特性与可解释性指标表；  
  - 典型规则 + 样本案例图。  
- 输出：  
  - Fuzzy-XFD 性能与规则可解释性主表；  
  - 规则+样本可视化图。

## 四、阶段3执行节奏与协同（与周次对应）

> 可与之前“Week 1–8” 时间线对齐使用，这里只给出阶段3的节奏建议。

### Week 1–2：统一基线与接口落地
- Explainable Toolkit：确认统一接口与批量运行脚本；  
- 数据/训练接口：所有新实验迁移到 VBench + 统一 trainer；  
- 各 Paper：对齐配置与基线模型选择。

### Week 3–4：各方法单独完成主实验
- 1D-2D、MoE、Operator Attention、Fuzzy：分别跑完与基线的对比实验；  
- Toolkit：逐步接入这些模型的解释，抽取指标。  
- NeSy：开始收集可用的“理论案例”数据。

### Week 5–6：组合实验与 LLM/NeSy 集成
- 重点进行：  
  - 1D-2D + Toolkit + MoE/OpAtt 的组合实验；  
  - Fuzzy + Toolkit 的规则级解释对齐；  
  - LLM Interface 使用统一解释输出进行质量/效率对比。  
- NeSy：初步撰写基于真实结果的理论分析段落。

### Week 7–8：结果整理与论文骨架对齐
- 各 Paper：将阶段3结果填入各自 `manuscript/draft_md` 的结果与讨论部分；  
- 全局：  
  - 对齐表格与图编号；  
  - 检查指标与定义在各文中是否一致；  
  - 准备一份综合性的“跨项目结果总结”文档。
